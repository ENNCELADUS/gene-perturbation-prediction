# Project Context

## Glossary

### A: Basal Context and Perturbation Target

The upstream input for a forward perturbation experiment. In the current K562
baseline, `A` is a control-cell expression state plus a minimal target
representation such as target-coordinate masking.

### B: Observed Post-Perturbation Response

The measured single-cell response distribution after perturbing a gene. Existing
experiments use Replogle or Adamson K562 Perturb-seq cells grouped by
perturbation gene.

### B_hat: Predicted Post-Perturbation Response

The predicted single-cell response distribution generated by an A->B model.
`B_hat` should be evaluated separately from observed `B` because forward-model
error can change downstream dependency ranking.

### Condition Group

An unordered group of cells sharing the same cell type, perturbation gene, and
batch when those annotations are available. A condition group is a distributional
unit; it does not imply one-to-one pairing between control cells and perturbed
cells.

### Cell Set / Window

A fixed-length or variable-length subset drawn from a condition group for
set-to-set perturbation modeling. Cell order inside a set/window is not
biologically meaningful and must not define reconstruction targets.

### C: Dependency Phenotype

The population-level DepMap/Achilles CRISPR GeneEffect label for the same
cell-line and perturbation-gene key. It is a dependency score, not a single-cell
death label and not a true synthetic-lethality label.

### Observed-B -> C

A downstream predictor trained and evaluated on measured post-perturbation
single-cell bags or summaries. This is the validated K562 bridge in the current
roadmap.

### Predicted-B -> C

A downstream predictor trained and evaluated on `B_hat` features. It tests
whether a predicted response distribution preserves enough signal for dependency
ranking.

### Prediction-Only Final Evaluation

The final internal or external test path for A->B->C models. It predicts
GeneEffect from control cells plus perturbation identity only, without using the
evaluated gene's observed post-perturbation response bag, target cell counts, or
target batch labels.

### Fold-Local A->B->C

A no-leakage evaluation setup where each CV fold trains A->B, the response-space
featureizer, prototypes, and the C predictor using train genes only. Test genes'
observed response cells are not used for A->B fitting, featureizer fitting, GMM
prototype fitting, or C-head fitting.

### Masked-Control Ridge

A linear A->B baseline that starts from control-cell expression, masks the target
gene coordinate when present, and predicts a post-perturbation expression delta
without an additional train-gene identity indicator.
