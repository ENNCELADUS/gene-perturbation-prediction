AIVC A→B→C model for GeneEffect prediction

A pretrained single-cell perturbation backbone (STATE) is turned into a differentiable virtual cell: a trainable perturbation adapter and a light response head map predicted transcriptomes to single-gene DepMap GeneEffect.

Train

  • Update (2.5e-5): PertAdapter · Expression projection · GMM occupancy · Prediction head
  • Fine-tune (2.5e-6): STATE (ST-HVG-Replogle) backbone
  • Access: observed expression X, DepMap labels c
L_total = 2·L_pred + 5·L_rank + 0.25·L_obs + L_aux
  • L_rank: pairwise RankNet · L_aux: B-space (annealed)

Eval / inference

  • No access: observed X or labels c; whole model frozen
  • Produce: ĉ = predicted GeneEffect, per gene
  • Apply (Bridge A): swap basal state → a-perturbed cells
s_A(a,b) = ½·( ĉ[b|ctrl]−ĉ[b|a] + ĉ[a|ctrl]−ĉ[a|b] )
  • symmetric co-dependency score: s_A(a,b) = s_A(b,a)

DepMap GeneEffect is a relative growth-rate effect under a population-dynamics model — single-gene, not a cell-death or single-cell readout, and never a double-knockout quantity.
