AIVC-0429

**同学 A：**
我先说一下我现在看到的数据。这个数据集好像是在几个癌细胞系里做了一组 pathway-level 的扰动，具体通路名称我还需要再回去确认。它大概是围绕几个 signaling pathways，比如 insulin signaling 或者其他 cancer-relevant pathways，选了一批 pathway-associated genes 做 perturbation。总共可能有两百多个 perturbation targets。

**同学 B：**
它是直接扰动 pathway，还是扰动 pathway 里的单个基因？

**同学 A：**
我现在理解是它实际扰动的还是单个 gene，只是这些 gene 是按 pathway 分组的。也就是说，不是“把整个 pathway 当成一个整体扰动”，而是选 pathway 里的关键基因逐个 perturb。数据里有每个 perturbation 之后的 gene expression profile，还有 log fold change、差异表达基因数量之类的指标。表里大概有一万八千多个 gene 的表达变化。

**老师：**
这个要区分清楚。如果是单个 gene perturbation，那最后的问题还是 gene-level 的。pathway 可以作为 annotation 或者 prior knowledge，但 synthetic lethality 最后还是要落到具体 gene 或 gene pair 上。不能把它直接说成 pathway-level SL，除非你后面真的定义 pathway-level dependency。

**同学 A：**
对，我也觉得这里要谨慎。这个数据可能不是直接给 SL label，而是给了 perturbation 之后的 transcriptomic response。它能告诉我们某个 gene 被 knockdown、knockout 或 activation 之后，细胞的表达谱发生了什么变化。

**同学 B：**
那它对我们项目到底有没有用？因为我们现在要做 synthetic lethality，感觉不仅要有癌细胞的 gene expression，还要知道敲掉某个 gene 之后细胞会不会死，或者这个 gene 是不是 essential。

**老师：**
对。这里有两个层次。第一层是 perturbation response，也就是扰动之后转录组怎么变。这个是 Perturb-seq / CRISPR screen with single-cell RNA-seq 这类数据能提供的。第二层才是 viability、fitness 或 essentiality，也就是这个扰动到底会不会降低细胞存活或生长。SL 更进一步，还要求这种 dependency 是 context-specific 的，比如只在某种 mutation background 或 cancer context 下出现。

**同学 A：**
所以这个数据本身不一定能直接作为 SL label，但可以作为中间表型？

**老师：**
对，可以这么理解。普通 AIVC 或 perturbation prediction 模型主要做到的是：给一个 unperturbed cell state 和一个 perturbation，预测 post-perturbation transcriptome。比如 GEARS、scGPT、State 这些模型，核心任务都是预测扰动后表达谱。GEARS 的问题定义就是输入未扰动表达状态和 perturbation set，输出扰动后的 transcriptional state；scGPT 也在 Adamson、Norman、Replogle 这些 Perturb-seq 数据上做 genetic perturbation prediction。 

**同学 B：**
但我们的项目不能只到表达谱为止，对吧？

**老师：**
对。我们想做的是在这个基础上再往后接一步：从 post-perturbation transcriptomic state 推断 cell fitness、dependency score，或者 synthetic-lethality-likeness。也就是说，我们不是只问“扰动后表达谱变成什么样”，而是问“这种表达变化是否意味着这个 cancer cell 更容易死亡，或者这个 gene 在这个背景下更 essential”。

**同学 A：**
那我之前想的是，我们能不能先不训练那个从未扰动到扰动后表达谱的模型？因为现在 forward perturbation prediction 本身很难，很多模型效果也没有特别好。我们可以先拿真实观测到的扰动后表达谱，直接去预测 SL 或 dependency。

**老师：**
这个作为第一阶段可以。但不能把 forward perturbation 这一步完全从故事里拿掉。否则就变成一个普通的 expression-to-dependency prediction，和 virtual cell / perturbation modeling 的关系就弱了。合理的说法是：第一阶段先用真实 post-perturbation expression 训练 downstream predictor，验证“扰动后转录组是否能预测 dependency”；第二阶段再接 forward perturbation model，用模型预测未测 perturbation 的表达后果，再进一步预测 dependency 或 SL candidate。

**同学 B：**
所以我们现在是两步：第一步，perturbation 到 post-perturbation transcriptome；第二步，post-perturbation transcriptome 到 viability / essentiality / SL-likeness。

**老师：**
对。第一步是 AIVC 领域已有的核心任务，第二步是我们项目的新增贡献。现在的缺口就是：扰动后的转录组变化到底意味着细胞死亡概率上升还是下降。这个连接如果能建立起来，就可以把 virtual cell 和 SL target discovery 接起来。

**同学 A：**
那 SL label 从哪里来？是不是可以用 DepMap？

**老师：**
可以先用 DepMap 的 CRISPR dependency / gene effect score。严格说，它不是直接的 single-cell death label，也不是严格意义上的 SL label。DepMap 给的是 cell-line-level 的 dependency phenotype：某个 gene 被 CRISPR knockout 后，这个 cell line 的 fitness 是否下降。也就是 gene effect score、essentiality score 或 dependency score。它反映的是 bulk-level 的细胞群体存活/增殖结果，不是单细胞层面的“这个细胞死了还是活着”。

**同学 B：**
那 DepMap 和 Perturb-seq 怎么接起来？

**老师：**
关键是对齐 cell line 和 perturbation gene。比如我们要找同一个 cell line，比如 K562、A549、HCT116 这类癌细胞系；然后找同一个 perturbed gene。如果 Perturb-seq 数据里有 K562 中某个 gene 的 CRISPRi perturbation expression profile，而 DepMap 里也有 K562 对这个 gene knockout 的 gene effect score，那么这个 cell line–gene pair 就可以作为一个训练样本。

**同学 A：**
也就是说，一个样本可以是：cell line = K562，perturbed gene = X，输入是 X 被扰动后的 expression change，label 是 DepMap 里 K562 对 gene X 的 dependency score。

**老师：**
对。更准确一点，输入可以是 delta expression，也就是 perturbation 后相对 control 的表达变化；也可以是 top DE genes、pathway activity score、或者 foundation model embedding。输出可以是连续的 gene effect score，也可以二值化成 essential / non-essential。但要注意，二值化阈值要谨慎，最好先保留连续 dependency score。

**同学 B：**
那 K562 是不是最好的起点？因为 Adamson、Norman、Replogle 都有 K562 的 perturbation 数据。

**老师：**
K562 确实是最自然的 proof-of-concept 起点。Adamson 是 K562 leukemia cell line 的 CRISPRi 单基因 Perturb-seq 数据，包含 87 个 one-gene perturbations；Norman 是 K562 的 CRISPRa 数据，包含 105 个单基因扰动和 131 个双基因扰动；Replogle 是 K562 的 genome-wide CRISPRi 数据，scGPT 处理中保留了 1,823 个具有较强 transcriptional phenotype 的 perturbations。

**同学 A：**
那 Norman 是 CRISPRa，DepMap 多数是 loss-of-function CRISPR knockout。这个能直接对齐吗？

**老师：**
不能完全直接对齐。Norman 的 CRISPRa 是 activation perturbation，它更适合做 combinatorial perturbation response prediction，或者研究 gene activation 后的 transcriptional effect。DepMap 的 CRISPR gene effect 更接近 loss-of-function dependency。所以如果要和 DepMap 对齐，优先考虑 CRISPRi 或 CRISPR knockout 的 Perturb-seq 数据，比如 Adamson 或 Replogle。Norman 可以作为方法参考或辅助数据，但不要把 CRISPRa activation 和 DepMap knockout essentiality 当作同一种 perturbation。

**同学 B：**
那如果某个 gene 在 DepMap 里 essential，是不是就可以叫 synthetic lethal？

**老师：**
不可以直接这么叫。Essentiality 只是说明这个 gene 对某个 cell line 的生长或存活很重要。Synthetic lethality 要求这个 dependency 和特定 genetic background 有关系，比如某个 tumor suppressor loss、driver mutation、paralog loss 或 pathway defect。更稳妥的表述是，我们先预测 context-specific dependency；然后再从这些 dependency 中筛选具有 cancer-selective 或 mutation-specific 特征的 SL candidates。

**同学 A：**
那我们需要正常细胞作对照吗？

**老师：**
最好有，但第一步可以先不强求。SL 的严格定义确实强调选择性：杀癌细胞，不杀正常细胞，或者只在特定 cancer genotype 下 lethal。可是从建模角度，第一阶段可以先学 cancer cell line 内部的 dependency；第二阶段再加入 normal cell、不同 cancer lineage、mutation status 或 copy-number background，去判断这种 dependency 是否具有 context specificity。

**同学 B：**
那死亡细胞的 transcriptome 怎么办？我们现在真实观测到的 Perturb-seq 细胞基本都是活着被测到的细胞。如果真正死掉的细胞已经消失了，我们怎么知道“死亡状态”的表达谱是什么？

**老师：**
这是一个关键矛盾。scRNA-seq 通常测到的是被捕获的活细胞或尚未完全死亡的细胞。真正死亡后，RNA 会降解，表达谱不一定能代表死亡前的 causal state。所以我们不能简单训练一个“活细胞表达谱 vs 死细胞表达谱”的分类器，因为可靠的死细胞转录组标签很难拿到。

**同学 A：**
那是不是可以用一些 apoptosis marker、stress marker，或者 dying-like cell state 来近似？

**老师：**
可以作为辅助特征，但不能当成完整答案。细胞死亡有多种机制，比如 apoptosis、ferroptosis、necrosis、senescence-associated arrest 等，不一定都会在相同 marker 上表现出来。有些 perturbation 可能导致细胞在被测到之前已经丢失，有些则可能只留下 surviving population 的 compensatory response。所以更可靠的 label 还是 bulk-level viability 或 DepMap gene effect score。

**同学 B：**
也就是说，我们不是直接预测“这个单细胞死没死”，而是预测“这个 perturbation 在这个 cell line 里造成的整体 fitness effect”。

**老师：**
对，这个表述更准确。我们可以把 single-cell transcriptomic response 聚合成 perturbation-level representation，比如每个 gene perturbation 对应一个 pseudobulk delta expression 或一个 distributional embedding。然后用这个 representation 去预测 cell-line-level dependency score。这样就避免把 DepMap label 错误解释成 single-cell death label。

**同学 A：**
那 viability screen 的实验逻辑我们应该怎么说？原来 transcript 里说是看 sgRNA 数量来反推死亡。

**老师：**
可以这样说：在 pooled CRISPR viability screen 里，每个 sgRNA 对应一个目标 gene。经过一段培养后，如果 targeting 某个 gene 的 sgRNA 在细胞群体中显著 depleted，说明敲除这个 gene 会降低细胞 fitness，导致携带该 sgRNA 的细胞增殖变慢或死亡。因此 sgRNA abundance 的变化可以用来估计 gene dependency。这个是 bulk / population-level readout，不是 single-cell RNA-seq readout。

**同学 B：**
那 Perturb-seq 和 DepMap 的本质区别就是：Perturb-seq 给我们扰动后的 transcriptome，DepMap 给我们扰动后的 fitness phenotype。

**老师：**
对。Perturb-seq 的优势是机制解释：它告诉我们哪些 genes、pathways、stress programs 或 compensatory programs 被改变。DepMap 的优势是功能标签：它告诉我们这个 gene loss 对 cell fitness 有没有影响。我们项目的关键就是把这两者连接起来。

**同学 A：**
那如果我们只拿 perturbation 后的真实 expression 去预测 DepMap dependency，是不是已经有意义？

**老师：**
有意义，作为第一阶段很合理。这个阶段的科学问题是：post-perturbation transcriptomic response 是否包含足够信息，可以预测同一个 cell line 中该 gene 的 dependency strength？如果能预测，说明扰动后表达谱确实承载了和 viability 相关的机制信息。

**同学 B：**
第二阶段才是更像 virtual cell：对实验没有覆盖的 perturbation，先预测表达谱，再预测 dependency。

**老师：**
对。第二阶段的任务可以写成：给定一个 cancer cell line 的 basal expression 和一个 candidate perturbation，模型先预测 post-perturbation transcriptome，再通过 downstream dependency predictor 给出 gene effect score 或 SL-likeness ranking。这样就形成一个 in silico perturbation-to-dependency pipeline。

**同学 A：**
但是现在 forward perturbation prediction 本身效果不好。之前 benchmark 也说很多 deep learning model 不一定超过 simple baseline。

**老师：**
这个要在讨论里诚实承认。现在学界对 perturbation response prediction 还没有完全解决，尤其是跨 cell context、unseen gene、combinatorial perturbation 的泛化都很难。已有 benchmark 也指出，一些 deep learning / foundation model 在单扰动或双扰动预测上并不稳定，甚至不一定优于简单线性 baseline。 所以我们不能把项目建立在“forward prediction 已经完美”这个假设上。

**同学 B：**
那我们怎么避免项目风险太大？

**老师：**
分阶段。第一阶段只做 observed perturbation transcriptome → observed dependency score。这里不依赖 forward model 的预测能力。第二阶段再接入 scGPT、GEARS、State 或者简单 additive / linear baseline，比较不同 forward model 生成的表达谱对 downstream dependency prediction 的影响。这样即使 forward model 不完美，我们也能量化误差从哪里来。

**同学 A：**
那最后项目可以怎么收敛？

**老师：**
可以收敛成三件事。第一，整理可对齐的数据：DepMap gene effect score，加上 K562、A549、HCT116 等癌细胞系的 Perturb-seq / CRISPRi expression response。第二，构建 matched cell line–gene perturbation table，把 transcriptomic delta 和 dependency label 对上。第三，训练一个 transcriptome-to-dependency model，先预测 gene effect score，再进一步评估哪些 predicted dependencies 具有 SL candidate 的特征，比如 cancer-specific、mutation-specific 或 pathway-specific。

**同学 B：**
所以我们现在不是直接说“预测 SL”，而是说“用 perturbation-induced transcriptomic response 预测 cancer dependency，并进一步 prioritise synthetic lethality candidates”。

**老师：**
对，这句话最准确。SL 是最终应用场景，dependency 是第一阶段更可靠的监督信号。不要一上来就说我们有 SL label；更严谨的说法是：DepMap 提供 essentiality / dependency label，我们用它来学习 perturbation response 和 cell fitness 的关系，再基于 context specificity 去筛选 SL candidates。

**同学 A：**
明白。那我接下来先做数据对齐，优先找 CRISPRi / knockout 的 Perturb-seq 数据，看哪些 cell line 和 DepMap 能对应上。K562 作为第一优先级，A549、HCT116 再确认。Norman 这种 CRISPRa 数据可以先放在方法参考里，不作为和 DepMap knockout label 直接对齐的主数据。

**老师：**
对。还有一点，文件格式上你刚才提到的 RDS、h5ad、matrix 文件都要分清楚。RDS 可能是 Seurat object 或作者处理后的对象；h5ad 更方便 Python / Scanpy 处理；如果是 raw count matrix，还要自己做 QC、normalization、batch correction 和 pseudobulk aggregation。不要只下载一个差异表达结果表就以为够了，最好拿到 cell-level count matrix 和 perturbation metadata。

**同学 B：**
因为我们最终需要每个 perturbation 的表达变化，不只是一个 DEG list。

**老师：**
对。最少需要 control cells、perturbed cells、perturbation label、cell line label，以及 gene expression matrix。然后才能算 delta expression 或 pseudobulk profile。后面再和 DepMap 的 model ID、gene symbol、Entrez ID 或 Ensembl ID 对齐。

**同学 A：**
那今天讨论的结论就是：我们不跳过扰动；也不直接把 essentiality 等同于 SL。我们先用真实扰动后的转录组，连接 DepMap dependency，验证 transcriptomic response 是否能预测 fitness effect。后面再接 virtual cell forward model，做未测扰动的 dependency ranking。

**老师：**
对，这就是现在比较合理、也比较可落地的路线。核心贡献不是“我们重新做一个 scGPT 或 GEARS”，而是把 AIVC 的 perturbation response prediction 和 cancer dependency / SL target discovery 连接起来。这个连接目前是有生物学意义的，也有数据可操作性。

## 可以作为会议最后一句的收束

**老师：**
所以我们现在的任务可以先这样定义：以 Perturb-seq 提供的 post-perturbation transcriptome 作为机制表征，以 DepMap gene effect score 作为功能标签，建立一个从扰动响应到 cancer dependency 的预测模型。第一阶段用真实观测表达谱验证这条关系；第二阶段再接入 virtual cell 模型预测未测 perturbation 的表达后果，并进一步排序潜在 SL targets。这个方向既保留了 perturbation modeling 的核心，也能落到 synthetic lethality target discovery 上。
