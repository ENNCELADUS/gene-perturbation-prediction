Stage two · SL benchmark

Multi-Study SL Benchmark: Baselines

Run benchmark_baselines_all_seed0_v2 on the H20 (port 30838), code aee1417, seed 0, 2026-11-13. Data card: SL benchmark (§4 describes each baseline).

Question

How well do published SL prediction methods rank SL pairs in held-out cell lines of the multi-study benchmark? The control is the training SL fraction: the share of the same study's training lines that called the pair SL. A model that reads the line must beat this control before it can show context.

Benchmark

  • Labels: data/sl_studies/benchmark_v2 on the H20; the SL split (configs/benchmarks/cell_line_sl_split.json) places 77 lines by hand, 44 train, 17 validation and 16 test.
  • A screen is the set of pairs that one study tested in one line with one method. The headline uses the genetic screens with both classes: recall in the top 10% of each screen, averaged over screens, then studies, then lines.
  • Negatives are tested and not called; they are not true negatives.

Rows

  • KG4SL (official code): a graph neural network on the SynLethKG knowledge graph, trained on the training lines' pairs.
  • Cilantro-SL (official code, refitted): Geneformer deletion embeddings and an MLP; it scores a pair only when both genes are in the line's top 2,048 tokens.
  • PARIS (Python port of the R code): random forests of each gene's GeneEffect on bulk expression in the training-side lines.
  • SLIdR (Python port of the R code): a rank test of the partner's GeneEffect in lines where the other gene is mutated, inside the lineage.
  • De Kegel 2021 paralog classifier: the released scores (Table S8).
  • Kebabci 2026 paralog classifier (official code, refitted on measured GeneEffect). The baseline row reads stage one's predicted GeneEffect (the linear expression model) in the held-out lines; the reference row reads measured GeneEffect.
  • MiT4SL (official code and protocol, refitted): a graph model on PrimeKG with a PPI graph of each line.
  • Controls and references: the training SL fraction, pan-essentiality (gene mean GeneEffect), stage one's predicted GeneEffect, measured GeneEffect, the labels (the ceiling) and a random score. Rows that score only part of the held-out pairs give the other pairs one fill score (see the card).

What ran

Each baseline wrote scores.parquet under outputs/sl/ (Cilantro-SL under outputs/cilantro_reproduction/benchmark_gc95M); the scorer read them all through configs/sl/benchmark_baselines.yaml. Output: outputs/sl/benchmark_baselines/benchmark_baselines_all_seed0_v2/; copied report: results.md, run_config.json. The per-line and per-screen tables (lines.csv, lists.csv, metrics.json) stay on the H20.

Reading

  • No baseline reaches the training SL fraction. Every interval in Table 2 is below zero on both splits.
  • The best baseline is the Kebabci paralog classifier on stage one's predicted GeneEffect (0.343 / 0.359, Table 1). On its own rows it comes near the training SL fraction (0.599 against 0.615 on test) with a higher AUROC (0.90 against 0.88, Table 4).
  • Predicted GeneEffect does not lose to measured GeneEffect in Kebabci. The predicted version also scores held-out lines without measured GeneEffect, so it is higher overall (0.343 / 0.359 against 0.283 / 0.270).
  • No baseline follows context. On seen pairs whose label differs from the training lines, every baseline is near random (0.07–0.11; the random score gives 0.08 / 0.09, Table 3).
  • PARIS, MiT4SL, Cilantro-SL and SLIdR are near random on all rows (0.09–0.21, Table 1). On its own rows SLIdR is at random (AUROC 0.49 / 0.51) and PARIS only a little above it (0.57 / 0.58, Table 4).
